# Imagens de teste

- `charts/` — cartelas geradas pelo próprio projeto (`npm run cartelas`): degradês, cores, sombras e zone plate (teste de moiré).
- `personal/` — fotos de teste (`foto-teste-01.jpg`…). São referências de terceiros, usadas só para testar o motor.

O harness lista automaticamente qualquer `.jpg`/`.png` colocado aqui, em `personal/` ou em `charts/`.
